# 📚 刷课脚本 使用说明

## 简介

自动检测网课页面的「当前任务已达到完成条件」弹窗并精准点击「下一个」，智能检测并启动视频播放，**支持课程系统音频（扬声器内录）自动分小节录制**。内嵌单次播放触发机制、画面静止防卡顿恢复、多尺度模板匹配与双轨切课定位，彻底杜绝误点「上一个」、文字笔画误判与未完成时误跳课。

---

## 核心功能与特色（v1.6）

1. **▶ 精准单次播放触发 + 画面静止防卡顿（全新机制）**：
   - **启动监控时**：单次触发点击一次播放（优先按键，未识别自动点视频中心）；
   - **切课（下一个）后**：等待页面加载（3.5 秒），单次触发点击一次播放；
   - **视频不动 / 暂停卡顿恢复**：通过轻量级画面动态检测，当检测到视频画面**连续静止超 12~15 秒且无切课弹窗**时，自动点击一次播放键或视频中心恢复播放；
   - **正常播放期间**：**100% 保持静默**，绝不重复点击播放键，彻底消除播放中误触暂停与识别波动！

2. **⚙️ 4 大实用播放模式（支持中心兜底）**：
   - **`智能识别 + 中心兜底 (推荐)`**：优先高精度识别播放按键/圆盘；若未识别到图标，自动点击视频中心区域触发播放（彻底解决未识别卡死）。
   - **`直接点击视频中心`**：免任何图像识别，触发时直接点击屏幕中央区域（极简可靠，通杀所有网页播放器）。
   - **`仅智能识别播放键`**：仅在明确检测到播放图标时点击一次。
   - **`模板匹配优先`**：优先使用截图模板 `play_button.png` 多尺度边缘匹配。

3. **🖥️ 宽屏舒适界面与自适应布局**：
   - 窗口拓宽至 `1120x800`，参数栏与状态卡片间距舒适宽敞，彻底消除拥挤挤压感。
   - 自动居中显示，完美适配 Windows 高 DPI 缩放与各类分辨率屏幕。

4. **🎙️ 系统音频内录（默认关闭，可按需开启）**：
   - **默认不开启录制**：避免不需要录音的用户默认占用系统音频资源。
   - **按需开启后智能联动**：
     - 当播放按钮被点击（或视频开始播放）时，**自动启动音频录制**；
     - 当任务完成点击「下一个」切课时，**自动停止并安全保存本节音频**；
     - 切换到新课程视频开始播放时，**自动开启新一节录音**；
     - 点击「停止监控」时，**自动保存正在录制的音频**。
   - **命名规范**：
     - 自动保存到 `recordings/` 目录下，文件命名格式为：
       `recordings/课程录音_第01节_20260824_163015.wav`
     - 采用标准无损 PCM 16-bit 44.1kHz 双声道 WAV 格式。
   - **一键查看**：界面提供「📁 打开录音目录」按钮，一键在资源管理器中打开录音文件夹。

5. **🎯 全场景双轨智能切课定位（彻底杜绝误点「上一个」）**：
   - **轨 1: 弹窗模式**：多尺度 (0.75x~1.30x) 检测完成弹窗并在 ROI 内精确定位「下一个」；
   - **轨 2: 独立按钮模式**：视频播放完毕页面独立亮起「下一个」时，全局多尺度高置信度锁定。

## 界面参数与设置

| 配置项 | 推荐值 | 功能说明 |
|---|---|---|
| **检测间隔** | `4~6 秒` (默认 4) | 主监控循环检测频率 |
| **弹窗匹配阈值** | `0.75~0.85` (默认 0.78) | 弹窗相似度门槛（支持多尺度缩放自适应） |
| **按钮匹配阈值** | `0.78~0.85` (默认 0.80) | 「下一个」按钮相似度门槛（防误点「上一个」） |
| **切课缓冲** | `3.5 秒` | 点击「下一个」后等待新小节页面与视频加载时间 |
| **自动播放** | 勾选 (开) | 仅在启动、切课后或画面静止时触发播放，正常播放中不点击 |
| **播放模式** | `智能识别 + 中心兜底 (推荐)` | 可选：直接点击视频中心 / 仅智能识别播放键 / 模板匹配优先 |
| **🎙️ 录制课程音频** | 默认不勾选 (关) | **可开关**：勾选后启用系统扬声器声音内录，按小节自动切分保存 |
| **📁 打开录音目录** | 按钮 | 一键在文件管理器中打开 `recordings/` 录音文件夹 |
