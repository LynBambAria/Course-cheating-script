# 📚 刷课脚本 使用说明

## 简介

自动检测在线课程页面中的「当前任务已达到完成条件」弹窗并点击「下一个」，同时自动检测并点击「播放」按钮，实现刷课自动化。

## 使用方法

### 1. 启动

双击桌面上的 **`刷课脚本.exe`** 即可打开程序界面。

### 2. 设置检测间隔

在 **「检测间隔」** 输入框中填写检测频率（单位：秒），建议 **5~30 秒**：
- 数值越小，检测越快，但 CPU 占用稍高
- 数值越大，检测越慢，但更省资源

### 3. 开始监控

点击 **「▶ 开始监控」** 按钮，脚本开始自动检测屏幕。

### 4. 停止监控

点击 **「⏹ 停止」** 按钮即可停止。

## 播放按钮检测说明

脚本会自动检测屏幕上的「播放」按钮并点击，**无需手动设置**。检测策略如下（按优先级）：

| 优先级 | 策略 | 说明 | 日志标记 |
|--------|------|------|----------|
| ① | **模板匹配** | 用截取的模板图片精确匹配按钮位置（需先截取模板） | `▶ [模板匹配] 点击播放按钮` |
| ② | **自动图像识别** | 通过 OpenCV 分析屏幕，找圆形按钮区域（不受背景颜色影响） | `▶ [自动识别] 霍夫圆检测到播放按钮` |
| ③ | **轮廓分析** | 边缘检测 + 圆形度分析，找接近圆形的轮廓 | `▶ [自动识别] 轮廓分析检测到播放按钮` |
| ④ | **屏幕中央** | 兜底方案，点击屏幕中央尝试播放 | `▶ [自动识别] 未找到圆形按钮，尝试屏幕中央` |

> 自动识别通过**霍夫圆检测**和**轮廓圆形度分析**来定位播放按钮，即使按钮背景颜色变化也能识别。日志中会明确标注当前使用的是哪种方法。

### 可选：截取播放按钮模板（提高识别精度）

如果想进一步提高识别精度，可以手动截取播放按钮模板：

1. 打开一个**未播放的视频页面**，让「播放」按钮显示在屏幕上
2. 点击程序中的 **「📷 截取播放按钮」** 按钮
3. 程序会提示 **"将鼠标移到播放按钮的左上角"**，你有 5 秒时间移动鼠标，**不要动**，等待提示变化
4. 接着提示 **"将鼠标移到播放按钮的右下角"**，同样有 5 秒时间
5. 截取成功后，状态会变为 **「✅ 已设置」**

## 工作原理

脚本在后台循环执行以下检测：

```
每轮循环:
  ├─ 检测「播放」按钮 → 有则点击（每 30 秒检测一次）
  │    ├─ ① 模板匹配（精确）
  │    ├─ ② 自动图像识别（霍夫圆检测）
  │    ├─ ③ 轮廓分析（圆形度）
  │    └─ ④ 屏幕中央（兜底）
  │
  └─ 检测「完成」弹窗 → 有则点击「下一个」
       ├─ ① 精确匹配按钮
       ├─ ② 宽范围匹配
       └─ ③ 硬编码坐标
```

- **播放按钮检测**：独立运行，与弹窗检测互不干扰。无论视频是刚跳转、手动暂停、还是未播放状态，都会自动点击播放。
- **弹窗检测**：检测到「当前任务已达到完成条件」弹窗后，依次尝试三种方式点击「下一个」。

## 注意事项

- 脚本运行时会**占用鼠标**，建议在刷课跳转的几秒内不要操作鼠标
- 如果弹窗位置发生变化，需要重新截取弹窗模板（联系开发者）
- 首次启动 exe 可能稍慢几秒，因为需要解压运行时环境
- 如遇到杀毒软件误报，添加信任即可
